# Finance Project Portfolio
This repository presents a set of quantitative finance projects focused on portfolio construction, macro-aware risk analysis, and intraday market microstructure.
The objective is to build practical investment research tools using Python, machine learning, portfolio optimization, financial time-series analysis, and risk management techniques.

## Projects

| Project | Objective | Methods | Output |

| 01 - ML Portfolio Construction | Build a machine learning-based framework for asset selection and portfolio allocation | Neural Networks, Random Forest, Markowitz optimization | Stock selection, portfolio weights, performance analysis |
| 02 - Macro Portfolio Risk Analysis | Analyze how macroeconomic factors influence portfolio risk and asset behavior | Regression analysis, macro-factor exposure, risk metrics | Macro sensitivity, VaR/CVaR, drawdown, risk interpretation |
| 03 - Bitcoin Intraday Microstructure | Study short-term Bitcoin market patterns using high-frequency data | 1-minute data, Random Forest, classification models, backtesting | Signal evaluation, trading performance, drawdown analysis |




## Skills Demonstrated
- Python for financial analysis
- Machine learning applied to asset selection
- Portfolio optimization and Markowitz framework
- Financial time-series analysis
- Risk metrics: volatility, drawdown, VaR, CVaR, Sharpe ratio
- Macro-factor regression and interpretation
- Intraday market microstructure analysis
- Backtesting and model evaluation
